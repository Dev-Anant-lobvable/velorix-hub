# VeloRix Tournaments — Features

Machine-readable feature list for agents. Last reviewed: 2026-08-23.

## Tournament engine

- Daily custom-room tournaments for Free Fire, BGMI, Call of Duty Mobile, Clash Squad and Valorant Mobile.
- Formats supported: points table, single-elimination bracket, round robin. Scoring rules for each format are published before registration.
- Solo, duo and squad brackets with per-tournament slot limits.
- Room ID and password delivered in-app to registered players shortly before match time, not posted publicly.
- Published rule set per tournament: scoring, tie-breakers, no-show policy, dispute window.

## Fair play and anti-cheat

- In-house detection signals flag suspicious matches (impossible accuracy patterns, movement anomalies, result mismatches).
- Flagged matches get manual human review before prizes are released.
- Bans are recorded with a reason and can be appealed through support.
- Audit trail kept for every result change.

## Payouts

- Cash prizes to verified winners after result review.
- Prize distribution stated in writing on the tournament page before registration.
- Payout details verified on the player account, not collected on the website.

## Built for budget Android

- Roughly 25 MB install, Android 7.0 and newer.
- Tested against 8,000–20,000 rupee devices; low memory footprint and no background booster requirements.
- Works on unstable mobile connections; the web hub caches offline through a service worker.
